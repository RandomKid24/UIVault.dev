Use befui without React

One stylesheet and one script. Works in Django, PHP, Rails or any plain HTML page. No build step, no dependencies.

Install

Paste into <head>. Everything on this page is running from these two files.

<link rel="stylesheet" href="https://unpkg.com/befui-web@1/befui.css">
<script src="https://unpkg.com/befui-web@1/befui.js" defer></script>

Or npm i befui-web and serve node_modules/befui-web/befui.css and befui.js yourself.

Theme

Colours are CSS variables on :root, the same names as the React version. Override any of them. Dark mode follows the OS; add class="dark" or class="light" to <html> to force it.

Button, input, checkbox, badge, card

Plain classes. Buttons also come as bf-btn-secondary -outline -ghost -destructive and -sm -lg.

<bf-select>

Write normal <option> tags inside. Add name and it posts with the form like a native select. Supports required, disabled, placeholder, <optgroup>, keyboard and type-to-find. On a phone it opens as a bottom sheet (try narrowing the window under 640px). Listen for change.

<bf-date-picker>

Value is YYYY-MM-DD, the same as <input type="date">. Attributes: name value min max required placeholder week-start (0 = Sunday). The label follows the page lang. Arrow keys move by day, PageUp/PageDown by month.

<bf-dialog>

Built on the native <dialog>: Esc closes it, focus is trapped, the page behind is inert. Open with data-bf-open="#id", close with data-bf-close, or call el.show() / el.close(). Put slot="footer" on the buttons. Phones get a bottom sheet.

<bf-toast>

From JavaScript: BefUI.toast(message, {type, duration, position}). Types: success warning error. duration is ms (0 keeps it until dismissed). Positions: top|bottom + left|center|right. Or drop a tag in the HTML your server returns and it shows itself.

Added later (htmx, fetch, innerHTML)

Elements set themselves up when they appear on the page, so there is nothing to re-initialise after a swap. This button inserts markup the way an htmx swap does.

Both are form fields, so htmx (hx-post on the form) sends their values too.

Good to know

Eventsinput and change bubble from <bf-select> and <bf-date-picker>. Read el.value, set el.value = '…'.
Validationrequired blocks submit and shows the browser's message. Change it with data-required-message.
BrowsersCurrent Chrome, Edge, Safari 16.4+, Firefox. Needs custom elements with form association.
SizeTwo files, no dependencies, no build step.
