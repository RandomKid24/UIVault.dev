Use without React New

One stylesheet and one script. Works in Django, PHP, Rails or any plain HTML page. Everything on this page runs from those two files.

Install

Paste into <head>. Or npm i befui-web and serve the two files yourself.

Usage
<link rel="stylesheet" href="https://unpkg.com/befui-web@1/befui.css">
<script src="https://unpkg.com/befui-web@1/befui.js" defer></script>

Theme

Colours are CSS variables on :root, the same names as the React version. Override any of them. Dark mode follows the OS; put class="dark" or class="light" on <html> to force it.

Button, input, checkbox, badge, card

Plain classes. Buttons also come as bf-btn-secondary -outline -ghost -destructive, and -sm -lg.

<bf-select>

Write normal <option> tags inside. With a name it posts with the form like a native select. Supports required, disabled, placeholder, <optgroup>, keyboard and type-to-find. On a phone it opens as a bottom sheet (narrow the window under 640px). Listen for change.

<bf-date-picker>

Value is YYYY-MM-DD, same as <input type="date">. Attributes: name value min max required placeholder week-start (0 = Sunday). Labels follow the page lang. Arrow keys move by day, PageUp/PageDown by month.

<bf-dialog>

Built on the native <dialog>: Esc closes it, focus stays inside, the page behind is inert. Open with data-bf-open="#id", close with data-bf-close, or call el.show() and el.close(). Put slot="footer" on the buttons. Phones get a bottom sheet.

<bf-toast>

From JavaScript: BefUI.toast(message, {type, duration, position}). Types success warning error. duration is in ms (0 keeps it until dismissed). Positions are top or bottom plus left, center or right. Or put a tag in the HTML your server returns and it shows itself.

Added later (htmx, fetch, innerHTML)

Elements set themselves up when they appear on the page, so nothing needs re-initialising after a swap. The button below inserts markup the way an htmx swap does. Both are form fields, so hx-post on the form sends their values.

Good to know

Eventsinput and change bubble from <bf-select> and <bf-date-picker>. Read el.value, set el.value = '…'.
Validationrequired blocks submit and shows the browser message. Change it with data-required-message.
BrowsersCurrent Chrome, Edge, Safari 16.4+ and Firefox.
SizeTwo files, no dependencies, no build step.
